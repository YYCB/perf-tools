# Rockchip RK3588 平台档案

适用于：Firefly ROC-RK3588-PC、Orange Pi 5、Radxa ROCK 5B 等 RK3588 单板机。

## 硬件规格

| 项 | 值 |
|---|---|
| SoC | Rockchip RK3588 |
| CPU | 4× Cortex-A76 @ 2.4 GHz + 4× Cortex-A55 @ 1.8 GHz |
| GPU | Mali-G610 MP4 |
| NPU | RKNPU2 @ 6 TOPS (INT8) |
| 内存 | LPDDR4x / LPDDR5（按板卡，典型 16 GB） |
| 存储 | eMMC 5.1 / NVMe（按板卡） |

## 关键工具

| 用途 | 命令 / 工具 |
|---|---|
| CPU 频率查看 | `cat /sys/devices/system/cpu/cpu*/cpufreq/cpuinfo_cur_freq` |
| CPU governor | `echo performance > /sys/devices/system/cpu/cpufreq/policy0/scaling_governor` |
| 温度监控 | `cat /sys/class/thermal/thermal_zone*/temp` |
| NPU 利用率 | `cat /sys/class/devfreq/fdab0000.npu/cur_freq` |
| NPU 推理 | `rknn-toolkit2`（Python）/ `librknn_api`（C/C++） |
| 视频编解码 | `rkmpp`（HW accelerated H.264/H.265） |
| GPU 利用率 | `cat /sys/class/devfreq/fb000000.gpu/cur_freq` |

## 频率锁定（跑分前必做）

```bash
# CPU：大核 + 小核全部 performance
for f in /sys/devices/system/cpu/cpufreq/policy*/scaling_governor; do
  echo performance | sudo tee "$f"
done

# GPU
echo performance | sudo tee /sys/class/devfreq/fb000000.gpu/governor

# NPU
echo performance | sudo tee /sys/class/devfreq/fdab0000.npu/governor

# 验证
for p in /sys/devices/system/cpu/cpufreq/policy*; do
  echo "$p: $(cat $p/cpuinfo_cur_freq) kHz"
done
```

## 温度基线（跑分前等待）

```bash
# 等待所有 thermal zone 降到 < 50°C
watch -n2 "paste \
  <(cat /sys/class/thermal/thermal_zone*/type) \
  <(awk '{printf \"%.1f°C\\n\", \$1/1000}' /sys/class/thermal/thermal_zone*/temp)"
```

## ROS 2 on RK3588

```bash
# Ubuntu 22.04 Arm64（Armbian / Orange Pi OS）
sudo apt-get install -y ros-humble-ros-base python3-colcon-common-extensions

# CycloneDDS（推荐，内存使用更低）
sudo apt-get install -y ros-humble-rmw-cyclonedds-cpp
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI=file:///path/to/config/cyclonedds.xml
```

## 已知陷阱

- ⚠️ RKNPU2 的 Python API（`rknn-toolkit2`）版本与驱动版本必须严格对应；更新内核后需重新安装驱动
- ⚠️ Mali-G610 OpenCL 驱动在部分系统上需手动安装，否则 GPU 功能不可用
- ⚠️ CPU 大核（A76）和小核（A55）性能差异显著，benchmark 要分别钉核（`taskset -c 4-7` vs `taskset -c 0-3`）
- ⚠️ eMMC 随机写 IOPS 较低（通常 < 5000 IOPS），rosbag 录制建议用外置 NVMe

## 快速测试

```bash
# 大核性能
taskset -c 4 ./benchmarks/system/cpu/sysbench/run.sh --platform=rk3588-a76 --threads=1

# 小核性能
taskset -c 0 ./benchmarks/system/cpu/sysbench/run.sh --platform=rk3588-a55 --threads=1

# 内存带宽
./benchmarks/system/memory/run.sh --platform=rk3588

# NPU（需先准备 .rknn 模型）
./benchmarks/system/npu/run.sh --platform=rk3588 --model=model.rknn
```
