# Rockchip RK3588 平台档案

> 状态：📝 stub。

## 硬件规格

| 项 | 值 |
|---|---|
| SoC | Rockchip RK3588 |
| CPU | 4× Cortex-A76 @ 2.4 GHz + 4× Cortex-A55 @ 1.8 GHz |
| GPU | Mali-G610 MP4 |
| NPU | RKNPU @ 6 TOPS (INT8) |
| 内存 | LPDDR4x / LPDDR5（按板卡） |

## 工具

- `rknn-toolkit2` — 模型转换 / 推理
- `rkmpp` — 视频编解码
- `armbian-config` / 板厂工具 — 频率与电源
